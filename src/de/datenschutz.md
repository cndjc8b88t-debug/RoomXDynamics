# Datenschutzerklärung

*Stand: 22. November 2026*

RoomXDynamics ist eine Raumklima-Simulation für iPhone. Diese Seite erklärt, was mit Ihren Daten in der App und auf dieser Website (roomxdynamics.com) geschieht. Beides wird unten getrennt behandelt. Die deutsche und die englische Fassung sind inhaltlich gleich und gleichrangig.

---

## Die App

Die App RoomXDynamics erhebt keine personenbezogenen Daten. Sie hat kein Nutzerkonto, keine Analyse, keine Werbung und kein Tracking, und sie enthält keine Software-Bausteine von Dritten (SDKs). Alle Berechnungen laufen auf Ihrem iPhone; nichts, was Sie eingeben, wird an uns oder an andere gesendet, und die App speichert Ihre Eingaben nicht.

Wenn Sie es in den Einstellungen Ihres iPhones erlaubt haben, kann Apple Absturzberichte und Nutzungsdaten mit App-Entwicklern teilen. Diese Berichte machen Sie für uns nicht erkennbar. Wir nutzen sie nur, um Fehler zu finden und zu beheben. Für den Umgang von Apple mit diesen Daten gilt die [Datenschutzrichtlinie von Apple](https://www.apple.com/de/legal/privacy/).

Die Datenschutzangaben im App Store sagen dasselbe: keine Daten erfasst.

## Diese Website

Diese Website hat keine Cookies, keine Analyse, keine Tracking-Pixel und keine eingebetteten Inhalte von Dritten. Sie nutzt die auf Ihrem Gerät vorhandenen Schriften; von einem Schriftdienst Dritter wird nichts geladen. Es gibt kein Formular, das Daten an einen Server sendet. Ein kleines Skript auf der Startseite ändert nur die Reihenfolge der Karten und startet das Video auf Wunsch; es speichert nichts und sendet nichts.

Die Website wird bei GitHub Pages betrieben, einem Dienst der GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Niederlande, und der GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. Das ist nötig, um die Website auszuliefern und sicher zu betreiben. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO; unser berechtigtes Interesse ist der sichere und zuverlässige Betrieb der Website.

GitHub kann diese Daten in den USA verarbeiten. GitHub ist nach dem EU-US Data Privacy Framework zertifiziert, für das die Europäische Kommission ein angemessenes Schutzniveau festgestellt hat (Art. 45 DSGVO). Wie lange GitHub diese Logdateien aufbewahrt, regelt die [Datenschutzerklärung von GitHub](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement); wir haben darauf keinen Zugriff.
